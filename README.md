## 这本书怎么读

每一条建议都是一张标准卡片，固定 7 个字段：

- **成本**（钱 / 时间 / 毅力）· **说人话**（一句话讲清）· **收益**（大 / 中 / 小）· **证据等级**（A 强 / B 中 / C 弱）· **风险**（低 / 中 / 高）· **来源**（指南 / 论文 / 官方文件）· **备注**

阅读页顶部可按性价比 / 证据等级 / 风险筛选，支持全文搜索。

## 骨架与来源

- **中华中医药学会《亚健康中医临床指南》（2020）**：亚健康定义与八型辨证（肝气郁结 / 肝郁脾虚 / 心脾两虚 / 肝肾阴虚 / 肺脾气虚 / 脾虚湿阻 / 肝郁化火 / 痰热内扰）
- **GB/T 46939—2025《中医体质分类与判定》**：2026 年 4 月实施的国家标准（前身为 2009 年中华中医药学会团体标准），九种体质与标准化辨识方法
- **国家中医药管理局《中医养生保健技术操作规范》（2010）**：刮痧、拔罐等外治法的官方定位
- **NICE（2021）/ CDC（2023）慢性疲劳管理**：分级运动疗法的撤销与 pacing 能量管理
- 功法（八段锦 / 太极拳）干预慢性疲劳与癌因性疲劳的 meta 分析、呼吸训练的 2023 meta、抗疲劳补充剂的证据分级、养生智商税的官方辟谣口径

## 重要声明

本书内容为个人整理，**不构成任何医疗建议**。亚健康调理不能替代疾病的诊断与治疗：疲劳持续超过 6 个月、伴体重下降 / 发热 / 盗汗等危险信号时请先就医；中药、针灸、推拿等务必经正规医疗机构执业医师辨证后进行。书中内容可能过时或有误，发现错漏欢迎提 issue。
